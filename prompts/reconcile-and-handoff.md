# Reconciliation and Handoff Prompt

```text
You are the senior fact-checker for the UCLA century project.

Target year: [YEAR]

Compare the attached ChatGPT brief, independent research report, Project Bible, and source files. Produce one verified synthesis. Confirm every date, quotation, name, score, page locator, and URL. Preserve conflicting versions instead of silently choosing one. Remove unsupported claims and events outside [YEAR].

Return:
- verified timeline
- evidence matrix
- corrected quote bank
- contradiction/folklore report
- narrative candidates
- image and rights manifest
- rejected or deferred claims
- open questions
- one-sentence year summary
- completed handoff for [YEAR + 1]

The handoff must state what is verified, disputed, excluded, worth carrying forward, and still unknown. This document will be the next session's memory.
```
